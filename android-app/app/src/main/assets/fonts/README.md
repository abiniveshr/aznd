# Flex card fonts

Open-source fonts used by the Flex share-card maker (`FlexFont` in `ui/common/share/FlexModel.kt`).
Copy this folder to `app/src/main/assets/fonts/`. If a file is missing, that font falls back to Sans.

All are licensed under the SIL Open Font License 1.1 (copies: `OFL-*.txt`), sourced from the Google Fonts repository.

| Font | File | Notes |
|---|---|---|
| Bebas Neue | BebasNeue-Regular.ttf | condensed capitals |
| Anton | Anton-Regular.ttf | heavy condensed headline face |
| Archivo Black | ArchivoBlack-Regular.ttf | heavy grotesque |
| Space Mono | SpaceMono-Regular.ttf, SpaceMono-Bold.ttf | monospace |
| Playfair Display | PlayfairDisplay-Variable.ttf | variable weight serif; weight set on load (API 26+) |
| DM Serif Display | DMSerifDisplay-Regular.ttf | high-contrast display serif |
